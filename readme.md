A beginner-friendly data pipeline project that automatically collects news articles and stores them in a database.

This project:
1. Gets news articles from NewsAPI
2. Cleans the data
3. Saves it to PostgreSQL database
4. Creates charts to visualize the data

Technology Used

- **Python** - Programming language
- **PostgreSQL** - Database
- **NewsAPI** - Where the news data comes from
- **Matplotlib** - For making charts
